# 🎯 Guessing Game

A number guessing game developed as part of Task 02 of my Software Development Internship at Prodigy InfoTech.

## Task Objective

Build a program that generates a random number and challenges the user to guess it.

The program provides feedback after each guess, indicating whether the guess is too high or too low. The game continues until the user correctly guesses the generated number and then displays the number of attempts taken.

## Features

- Generates a random number between 1 and 100
- User-friendly graphical interface
- Accepts user guesses
- Provides "too high" feedback
- Provides "too low" feedback
- Tracks the number of attempts
- Displays the result after a correct guess
- Input validation
- Prevents invalid numbers outside the range
- Play Again functionality
- Enter-key support
- Responsive design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

1. The program generates a random number between 1 and 100.
2. The user enters a guess.
3. The guess is compared with the generated number.
4. If the guess is lower, the user receives a "too low" message.
5. If the guess is higher, the user receives a "too high" message.
6. The game continues until the correct number is guessed.
7. The total number of attempts is displayed.
8. The user can start a new game using the Play Again button.

## How to Run

1. Clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
